# Gestor de Aula

Aplicación web sencilla para gestionar grupos de clase, alumnado y herramientas útiles dentro del aula.

## Funcionalidades
- Crear grupos de clase y añadir alumnos.
- Registrar asistencias y notas de cada alumno basadas en criterios e instrumentos de evaluación.
- Apartado de **Herramientas del Aula** con temporizador, cronómetro y selector aleatorio de alumnado.

## Requisitos
- Python 3.11+
- Dependencias indicadas en `requirements.txt`

## Uso

1. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```
2. Ejecutar la aplicación:
   ```bash
   python app.py
   ```
3. Abrir `http://localhost:5000` en el navegador.

Esta es una base mínima sobre la que seguir ampliando funcionalidades.
